Docker Quick Commands

รวมคำสั่งพื้นฐานสำหรับตรวจสอบและจัดการ Container อย่างรวดเร็ว

docker ps
docker ps -a
docker images
docker logs -f <container>
docker exec -it <container> /bin/sh
docker restart <container>

ข้อควรระวัง: ตรวจชื่อ Container และ environment ให้ถูกต้องก่อนสั่งลบหรือ restart บน Production
